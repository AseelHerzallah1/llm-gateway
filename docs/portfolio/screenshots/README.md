# Portfolio screenshots

Save PNG or JPG files here, then they appear in the root README.

| File | What to capture |
|------|-----------------|
| `dashboard.png` | http://127.0.0.1:8001/dashboard — blur/mask API key |
| `pii-redaction.png` | Top of `docs/portfolio/report.html` (PII table) |
| `report-cache-streaming.png` | Bottom of `report.html` (SSE + cache + metrics) — optional |

Generate a fresh report before capturing:

```powershell
python scripts/generate_screenshot_report.py
```
